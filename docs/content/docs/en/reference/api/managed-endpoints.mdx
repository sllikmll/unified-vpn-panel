## Subscription compatibility

| Protocol | Raw subscription | JSON subscription | Clash/Mihomo |
| --- | --- | --- | --- |
| VMess, VLESS, Trojan, Shadowsocks, Hysteria, MTProto | emitted unchanged | emitted where existing Xray JSON supports it | emitted where existing Clash/Mihomo builders support it |
| WireGuard legacy inbound | existing behavior unchanged | existing WireGuard JSON behavior unchanged | existing Mihomo WireGuard behavior unchanged |
| HTTP, Mixed, Tunnel and other no-link legacy protocols | existing behavior unchanged; omitted when there is no share URL | omitted | omitted |
| AmneziaWG 2.0 managed endpoint | `awg://` plus base64url-encoded full WireGuard/Amnezia config with keys, address, DNS, MTU, endpoint, keepalive, and AWG2 Jc/Jmin/Jmax/S1-S4/H1-H4 fields | unsupported, omitted | emitted as `type: wireguard` with `amnezia-wg-option` |
| Mieru managed endpoint | `mierus://` server-generated link accepted by current Mieru simple-link clients | unsupported, omitted | unsupported, omitted |
| NaiveProxy managed endpoint | `naive+https://user:password@host:port` with URL-escaped credentials | unsupported, omitted | emitted as `type: http` with TLS, username, and password |
